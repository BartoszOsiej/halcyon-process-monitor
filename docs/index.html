What it does

Kernel-level observability without the overhead. No agents. No sidecars. Just eBPF.

🔬

Kernel-Level Tracing

Traces execve, openat, connect, accept, sendto, recvfrom syscalls at the kernel level using eBPF tracepoints.

📊

7-Panel TUI

Live terminal dashboard with Events, Processes, Network, TopFiles, Extensions, Alerts, and Ransomware Heatmap panels.

🛡️

Ransomware Detection

Continuously scores per-process file-open rates against a sliding window to flag ransomware-style mass file access in real-time.

⚡

Zero-Copy Pipeline

Fixed-size ProcessEvent structs through per-CPU PerfEventArray. No allocations. No locks. Kernel to userspace in nanoseconds.

🌐

Network Tracing

Captures TCP/UDP connections with destination IP, port, protocol, and byte count — all from the kernel.

🐳

Docker & Kubernetes

Runs in containers with --privileged. Includes K8s DaemonSet, ServiceMonitor, and Prometheus metrics.

Get started in 30 seconds

One command. Full kernel observability.

# Clone and build $ git clone https://github.com/BartoszOsiej/halcyon-process-monitor $ cd halcyon-process-monitor && cargo build --release # Run (requires root for eBPF) $ sudo ./target/release/process-monitor 🔬 Halcyon Process Monitor v0.1.0 eBPF programs loaded. Tracing syscalls... Press 'q' to quit, '?' for help # Or run in Docker $ docker run --privileged -it ghcr.io/bartoszosiej/halcyon:latest
